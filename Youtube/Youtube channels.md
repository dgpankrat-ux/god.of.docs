# Архив видео и подкастов (2021–2024)

## 2024

- **[Grammar's great divide: The Oxford comma](https://youtu.be/ptM7FzyjtRk)** — Видеоролик, разбирающий многолетний спор вокруг оксфордской запятой и аргументы сторонников и противников её использования.

## 2023

- **[Podcast: Vanya and AsciiDoc](https://newpodcast2.live/podcast/vanya-and-asiidoc/)** — Выпуск подкаста, посвящённый опыту использования формата разметки AsciiDoc в технической документации.
- **[Podcast: All about Redocly, with founder Adam Altman](https://idratherbewriting.com/blog/redocly-podcast/)** — Выпуск подкаста Тома Джонсона с основателем Redocly о развитии инструмента и рынка API-документации.
- **[Презентація: ChatGPT для документації OpenAPI](https://youtu.be/LAEgnPLQieM)** — Запись доклада о применении ChatGPT для работы с OpenAPI-документацией, с наглядным демо ближе к концу.
- **[MkDocs + Material: старт публикации на GitHub Pages](https://youtu.be/Q-YA_dA8C20)** — Видеоурок о том, как настроить генератор документации MkDocs с темой Material и опубликовать первый сайт на GitHub Pages.
- **[GraphQL vs REST API для техрайтерів (вебінар)](https://youtu.be/Crz5VDrNj9o)** — Запись вебинара сеньор-техрайтера о специфике документирования GraphQL API в сравнении с REST.
- **[Writerside як standalone-тул](https://youtu.be/wjGPVFF1oHw?si=h-cdcdENTV4nqMK3)** — Видео Анны Гаспарян о том, как начать работу с JetBrains Writerside в его новой автономной версии.

## 2022

- **[Podcast 119: Trends in Technical Communication for 2022 and Beyond](https://www.cherryleaf.com/2021/12/podcast-119-trends-in-technical-communication-for-2022-and-beyond/)** — Выпуск подкаста Cherryleaf с прогнозами технических писателей на 2022 год.
- **[Бесплатный урок по системному анализу и системному мышлению](https://youtu.be/3Svcb7fGbZs)** — Вводный видеоурок про системный анализ и системное мышление для специалистов по требованиям.
- **[О ясности, а не дружелюбии в текстах](https://vimeo.com/343058726)** — Видео о том, что автору текста иногда важнее быть предельно понятным, чем стараться выглядеть дружелюбным или остроумным.
- **[Видео о Notion (в контексте ИИ)](https://www.youtube.com/watch?v=FElBbgnNtVA)** — Видео, по всей видимости, о возможностях ИИ-инструментов вроде Notion AI, обсуждаемое в контексте будущего профессии технического писателя.
- **[Intro to DocFX](https://learn.microsoft.com/en-us/shows/on-net/intro-to-docfx)** — Видео от команды Microsoft .NET о генераторе сайтов документации DocFX и его месте в DocOps-процессах.

## 2021

- **[Описание методов API в Confluence](https://youtu.be/yC89zNQSipE)** — Видео о практике описания методов API прямо в Confluence.
- **[KM talks — Игорь Цупко. О карте продуктов и услуг по менеджменту знаний](https://youtube.com/watch?v=8H5ZFQufoRI)** — Обзорное видео о продуктах и сервисах для управления знаниями в компании.
- **[Sphinx & Read the Docs](https://www.youtube.com/watch?v=oJsUvBQyHBs)** — Скринкаст о том, как начать работать с генератором документации Sphinx и хостингом Read the Docs.
- **[Podlodka #103 — Управление знаниями](https://soundcloud.com/podlodka/podlodka-103-upravlenie-znaniyami)** — Выпуск подкаста Podlodka об управлении знаниями в командах.
- **[Подборка выпусков про UX-писательство](https://www.youtube.com/watch?v=izsC0jKQGt8&list=PLSeEs69ieqI36laWi6PaLh5RRLkxDE7Ss)** — Плейлист на YouTube с архивом выпусков подкаста об UX-письме.
- **[Swimm — Getting Started](https://www.youtube.com/watch?v=Fm27CR5zyNI)** — Видео-инструкция о том, как начать пользоваться сервисом Swimm.
- **[Docusaurus (видеообзор)](https://www.youtube.com/watch?v=v5RRVGwmyno)** — Видеообзор генератора статических сайтов Docusaurus, часто используемого для документации.
- **[Backstage (видеообзор)](https://www.youtube.com/watch?v=_IJadjZg2Gw)** — Видеообзор платформы Backstage и её возможностей для организации документации разработчика.
- **[Gatsby 4](https://www.youtube.com/watch?v=5ob80szzLJM&t=774s)** — Обзор нового Gatsby 4 с ускоренной сборкой и SSR — фреймворк, который применяют и для сайтов документации.
- **[Собираем документацию на основе программной модели](https://www.youtube.com/watch?v=5Adgq-4KJoo)** — Демонстрация генерации документации из комментариев в коде с помощью Sphinx.
- **[Основы UX-текстов](https://www.youtube.com/watch?v=ZEoLJ6XvSSU)** — Вводное видео о видах интерфейсных текстов, влияющих на них метриках и тёмных паттернах.
