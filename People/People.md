# Люди, блоги и сообщества

Личные блоги техрайтеров, за которыми стоит следить, менторские программы, комьюнити и отраслевые отчёты/опросы (зарплаты, состояние индустрии).

## 2021

- **[Словарь технических терминов на русском языке](https://ru.meta.stackoverflow.com/questions/1267/%D0%A1%D0%BB%D0%BE%D0%B2%D0%B0%D1%80%D1%8C-%D1%82%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D1%85-%D1%82%D0%B5%D1%80%D0%BC%D0%B8%D0%BD%D0%BE%D0%B2-%D0%BD%D0%B0-%D1%80%D1%83%D1%81%D1%81%D0%BA%D0%BE%D0%BC-%D1%8F%D0%B7%D1%8B%D0%BA%D0%B5)** — Коллективный словарь и обсуждение перевода технических терминов на русский язык на meta Stack Overflow.
- **[Career Ladders for Technical Writers](https://career-ladders.dev/docs/)** — Открытая карьерная лестница технического писателя от Netlify — от Junior до Principal, которую можно адаптировать под себя.
- **[Society for Technical Communication — Mentor Board](https://www.stc.org/membership/mentor-board/)** — Бесплатная менторская программа STC для технических писателей и специалистов по технической коммуникации.
- **[UX Coffee Hours](https://storage.googleapis.com/uxcoffeehours.com/site/writing.html)** — Бесплатная менторская программа для UX-специалистов, включая UX-писателей и контент-стратегов.
- **[ADPList](https://adplist.org/)** — Платформа для поиска менторов среди дизайнеров, где есть и UX-писатели.
- **[UX Writing Hub](https://airtable.com/shrb65JXcazuyzzAy)** — Менторская программа специально для UX-писателей.
- **[Top Documentarian (CNCF Community Awards 2021)](https://lists.cncf.io/g/cncf-toc/message/6062)** — Анонс новой номинации для технических писателей в рамках премии CNCF Community Awards.
- **[Write the Docs Salary Survey 2021](https://salary-survey.writethedocs.org/)** — Ежегодный опрос о зарплатах технических писателей от сообщества Write the Docs.

## 2022

- **[SmartBear State of Software Quality: API](https://smartbear.com/state-of-software-quality/api/)** — Опрос SmartBear о состоянии индустрии API, включая важность документации.
- **[Postman State of the API](https://www.postman.com/state-of-api/)** — Ежегодный отчёт Postman о состоянии API-индустрии.
- **[Google State of DevOps 2021](https://services.google.com/fh/files/misc/state-of-devops-2021.pdf)** — Ежегодный отчёт Google о состоянии DevOps-практик с упоминанием ценности документации.
- **[Write the Docs Salary Survey 2020](https://www.writethedocs.org/surveys/salary-survey/2020/#overall-median-salary-employees)** — Результаты опроса о зарплатах технических писателей за 2020 год.
- **[Write the Docs Salary Survey 2019](https://www.writethedocs.org/surveys/salary-survey/2019/#median-salary-by-region-and-country)** — Результаты опроса о зарплатах технических писателей за 2019 год.
- **[Write the Docs Slack](https://www.writethedocs.org/slack/)** — Slack-сообщество Write the Docs с отдельными каналами под конкретные инструменты техрайтеров.
- **[technicalwriting.link](https://technicalwriting.link/)** — Курируемый агрегатор полезных статей, инструментов и материалов по технической коммуникации.
- **[SoftServe Technical Communication (блог на Medium)](https://medium.com/softserve-technical-communication)** — Корпоративный блог технических коммуникаторов SoftServe на Medium со статьями, полезными в первую очередь новичкам в профессии.

## 2023

- **[TW-DOCS (сайт автора)](https://tw-docs.com/ua/)** — Личный сайт-блог автора канала о технической документации, переехавший на новый домен.
- **[r/technicalwriting101](https://www.reddit.com/r/technicalwriting101/)** — Сабреддит-сообщество, где обсуждают основы и практику профессии технического писателя.
- **[База знань для UX-письменників](https://iramotorina.medium.com/%D0%B1%D0%B0%D0%B7%D0%B0-%D0%B7%D0%BD%D0%B0%D0%BD%D0%B8%D0%B9-%D0%B4%D0%BB%D1%8F-ux-%D0%BF%D0%B8%D1%81%D0%B0%D1%82%D0%B5%D0%BB%D0%B5%D0%B9-200492da10f)** — Курируемая подборка материалов на русском языке о UX-текстах, проектировании интерфейсов, исследованиях и локализации.
- **[How did I become a tech writer](https://passo.uno/how-did-i-become-tech-writer/)** — Личная история итальянского техрайтера Fabrizio о пути в профессию и роли комьюнити Write the Docs.
- **[techwriter.pl](https://techwriter.pl/)** — Сайт польского техрайтера с материалами о технической документации.

## 2024

- **[Portfolio — Peter Gustafson (pdgseo.com)](https://www.pdgseo.com/portfolio)** — Портфолио сениор-техрайтера и бизнес-аналитика Питера Густафсона с примерами описаний API, выполненное на WordPress вопреки идее docs-as-code.
